# Learning-OpenGL
This repo will hold all of my progress on learning OpenGL. 

How I'm learning
----------------

I'm using the udemy course: [Computer Graphics with Modern OpenGL and C++](https://www.udemy.com/course/graphics-with-modern-opengl/) by Ben Cook. 

What Exactly am I learning?
---------------------------

As mentioned I will be learning the basics of OpenGL, but what exactly does that entail?
The topics include but aren't limited to: 
- Understanding the OpenGL pipeline.
- What Shaders are in OpenGL.
- How rendering works.
- 3D and Linear Algebra (with [_3Blue1Brown's_](https://www.youtube.com/watch?v=fNk_zzaMoSs&list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab) playlist).
- Build Systems in C++ with CMake.

Essentially, every topic that the udemy course goes over will be documented in this repo and more. As mentioned I will be learning CMake, but I will be doing a more hands on approach. 

Instead of me learning like how I did in the past with my Learning CMake repo, I will instead use the [GLFW template](https://github.com/meemknight/GLFWCMakeSetup) that [_Low Level Game Dev_](https://www.youtube.com/watch?v=FrVABOhRyQg&t=203s) created and learn CMake while also learning OpenGL!
